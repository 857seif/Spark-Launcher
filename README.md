## ✨ Features

### 🎮 Version & Mod Loader Management
* **Universal Compatibility:** Play any official Minecraft Java release, snapshot, or historical version.
* **One-Click Mod Loaders:** Automatic installation and configuration for **Fabric**, **Forge**, **NeoForge**, and **Quilt**.
* **Instance Manager:** Create isolated profiles with dedicated game directories, custom Java arguments, and individual mod sets.

### 🌐 Built-in Server Hosting
* **Instant Local Hosting:** Host servers directly from your machine using **Vanilla**, **Paper**, **Purpur**, **Forge**, **Fabric Server** or **add your own version**.
* **Zero-Config Port Forwarding:** Integrated tunneling (UPnP / local tunnel integration) so friends can join your server without messing with router settings.
* **Server Dashboard:** Live RAM usage monitoring, real-time console control, and whitelist management directly from the Spark UI.

### 🚀 Built-In FPS Booster & Performance Enhancer
* **Auto-Tuned JVM Flags:** Applies optimized garbage collection (G1GC/ZGC) flags tailored to your system's RAM setup.
* **Dynamic Mod Injector:** Auto-suggests and installs top-tier performance mods based on your chosen version and loader:
  * **Fabric / Quilt:** *Sodium, Lithium, FerriteCore, Indium*
  * **Forge / NeoForge:** *Rubidium, ModernFix, Embeddium*
* **Low-Memory Mode:** Automatically frees unallocated heap memory and throttles background operations while the game runs.

### 🔓 Offline Support
* **Offline / Cracked Play:** Launch and play locally without requiring a Microsoft account authentication.

### 💾 Ultra-Lightweight
* **RAM Footprint:** Only **50-60 MB** — lighter than a browser tab.
* **Dead Machine Compatible:** Runs smoothly on old, low-spec, or "dead" hardware that struggles with other launchers.

### 🛠️ Developer Friendly
* **Easy to Extend:** Clean, modular codebase designed for customization and community contributions.
* **Open Architecture:** Add your own server types, mod sources, or UI themes with minimal effort.

### 📦 All-in-One Downloader
* **Download Everything:** Mods, game versions, resource packs, shader packs, server files, and more — all from within the launcher.
